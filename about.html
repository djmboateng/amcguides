About

A self-taught project, still growing

A product guide I'm building as I learn the gear myself.

I'm David Boateng, a Computer Engineering student at George Mason University and a frontend web developer with hands-on experience in AV systems.

This site is a self-taught initiative. Everything here comes from my own time with the Yamaha MG16XU: reading the manual, working the board and figuring out how each control affects the sound. I'm writing it down so the next person can learn it faster.

Where it's headed

It starts with the MG16XU, which will stay free. As I keep expanding my product knowledge, I'll add courses on the MG16XU, then guides for the rest of the Yamaha MG series along with extra operations and reference material.

The project grows as I do, so expect it to change and improve over time.
